# CrediULEP — Plataforma Financiera Encriptada (AES-256-GCM)

Plataforma financiera integral con Portal de Clientes (solicitud de crédito paso a paso con firma electrónica OTP), Panel de Trabajadores (Operadores/Analistas) y Panel Administrativo con matriz de edición en línea (`Inline Data Grid`) y auditoría criptográfica encadenada.

## Resumen Rápido para GitHub Pages

1. Ve a **Settings** -> **Pages** en tu repositorio de GitHub.
2. En **Branch**, selecciona `main` y la carpeta **`/docs`**, luego pulsa **Save** (o selecciona **GitHub Actions** como fuente).
3. Tu página estará disponible inmediatamente en `https://<tu-usuario>.github.io/<tu-repositorio>/`.
